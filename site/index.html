GOOGLE DRIVE ACCESS

A clear permission boundary.

PaPa-TDL requests drive.file to create the destination folder, upload your selected Telegram media and check files available to this app. It does not request unrestricted access to every file in your Drive. Each user signs into their own Google account.

Google tokens and the Telegram browser session stay in the private data directory on the machine running the app. Media may remain in temporary or pending storage there until a transfer completes. The maintainer does not operate a central file-transfer backend for this application.

On a remote VPS, browser sign-in currently needs an SSH port forward. Google may restrict access while the OAuth application is in testing or review; this page does not claim Google verification.

Know the limits

Telegram Web exposes only part of a chat. This is a watcher for rendered recent and new media, not a guaranteed full-history exporter. Outages, bursts and interface changes can cause missed transfers. Account permissions and protected-media controls are not bypassed. Files stay private by default; a Drive link still requires access.
