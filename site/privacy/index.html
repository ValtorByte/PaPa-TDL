DATA & ACCOUNT ACCESS

Privacy policy

PaPa-TDL is self-hosted software. Your transfers run on the machine where you install it.

Effective date: October 23, 2026 · Maintainer: ValtorByte · thevaltorbyte@gmail.com

What the application accesses

PaPa-TDL uses your authenticated Telegram Web account to locate a selected group, read rendered messages and download media you are authorized to access. Login uses your phone number, login code and two-step password when Telegram requires it. Browser profile and session data are retained locally so you can remain signed in.

If you choose Google Drive, Google authenticates you in its authorization flow. PaPa-TDL does not ask for your Google account password. It requests https://www.googleapis.com/auth/drive.file to create and reuse a destination folder, upload files, and read metadata such as identifiers, sizes and checksums for files available to the app. This scope does not provide unrestricted access to your entire Drive.

Where data goes

Downloaded media and necessary metadata move from Telegram to your runtime machine and, when you select Drive, from that machine to Google Drive. Local mode stores files in your chosen directory without requiring Google authorization. Original filenames, safe message-based names and checksums may be used to identify and verify transfers.

The distributed Desktop OAuth client identity identifies PaPa-TDL to Google; it is shared app configuration, not a user login token. Each user's authorization tokens are separate and are stored in that user's private runtime data directory. The maintainer does not receive your tokens or media through a central PaPa-TDL backend.

Storage, logs and retention

Your runtime machine holds configuration, the Telegram browser profile, Google tokens, downloads, transfer state and operational logs. Logs can include filenames, transfer progress, message identifiers, destination identifiers and errors. Do not share the private data directory or unreviewed logs. Login codes, passwords and session contents are not intentionally printed.

Pending downloads can remain on the runtime machine until the destination is verified or you remove them. Saved destination files remain until you delete them. Stopping the watcher does not erase account sessions or completed files. Operators of a shared or managed server may be able to access files on that server; choose a machine and account you trust.

Sharing and use

Files are private by default. A Drive URL does not make a file anonymously accessible. PaPa-TDL does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. Google data is used to provide the file storage and verification features you request. PaPa-TDL's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Your controls

Stop the watcher before removing credentials. Revoke Google access from your Google Account connections, and revoke the Telegram session from Telegram's Devices settings. Remove saved credentials and browser profiles from the runtime data directory after revoking access. Delete destination files separately in Drive or on your server. Revoking authorization does not delete files already saved.

This website and support

These static product pages do not include analytics, advertising, third-party fonts or sign-in forms, and do not intentionally set cookies. The hosting network must process request information such as IP addresses and requested paths to deliver pages; host infrastructure may retain security or diagnostic records. Other pages on this domain may have separate practices.

If you contact the maintainer or open a public GitHub issue, share only the information needed for support. Never attach tokens, OAuth JSON, browser profiles or private media. Public issues are visible to others.

Third-party services and changes

Telegram, Google and your hosting provider process data under their own policies. This project is not affiliated with or endorsed by Telegram or Google. This policy may be updated with changes to the software; the effective date identifies this version. Contact thevaltorbyte@gmail.com with privacy questions.
